How Browsers Work

Opening a website

When you enter a URL, the browser has to find the website's server, make a connection, and request the files it needs. Most websites use several files, including HTML, CSS, JavaScript, images, and fonts.

  1. Find the server: DNS helps match the domain name with an IP address.
  2. Connect:HTTPS uses TLS to protect information sent between the browser and the site.
  3. Request files:The browser downloads the website's HTML and other resources.
  4. Build the page:HTML and CSS are processed while JavaScript can add behavior.
  5. Display and interact:The browser draws the page and responds to clicks, typing, and scrolling.

Rendering a webpage

The browser processes HTML into a document structure called the DOM. It also processes CSS styling. From there, it works out the layout, paints the visual pieces, and combines everything into what you see on the screen.

Comparing browser engines

A rendering engine decides how website content gets displayed. Different browsers may share the same engine, which is one reason some browsers behave similarly.
